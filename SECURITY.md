# Security

## Reporting a vulnerability

If you discover a security issue in Daredevil, please report it responsibly:

1. **Do not** open a public GitHub issue for security vulnerabilities.
2. Send details to the maintainers (e.g. via the contact email in the repo or your preferred private channel).
3. Include steps to reproduce, impact, and any suggested fix if you have one.
4. Allow time for a fix before any public disclosure.

We appreciate your help in keeping the project and its users safe.
